# GraphPilot

A LangGraph agent for inspectable tool execution, persistent sessions and USB Android control.

This repository contains the agent. The independent [USBPhone Control](https://github.com/obsessed-star/usbphone-control) project owns the Android transport. Model providers are selected through LiteLLM; Groq is the initial configuration.

Implementation and validation are recorded as separate, chronological commits. No backdated activity or simulated live-provider results.
